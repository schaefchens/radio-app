# herde protocol fixtures (copy)

What a herde worker and a project say to each other, one exchange per file. This is a copy of
`protocol/fixtures/` in github.com/schaefchens/herde, at protocol version 2. The station answers
each request in its response's shape (`server/tests/cases/workers.php`, "the protocol's example
exchanges"). After a protocol change in herde, copy the files again; a test that fails then
shows where the station falls behind.
